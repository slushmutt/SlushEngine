Detailed Description

Behaviors are the main class that game scripts will derive from.

Behaviors allow game scripts to use lifecycle functions, such as Start(), Update() and many others.
Behaviors can be auto loaded at runtime if the class also inherits from AutoRegister.
The simplest behavior to make an application run properly is seen below:

main_behavior.h

#include <SlushEngine/behavior.h>
#include <SlushEngine/auto_register.h>
class MainBehavior : public SlushEngine::Behavior, private SlushEngine::AutoRegister<MainBehavior> {
public:
// Required to allow the Behavior to auto register at runtime.
MainBehavior(){(void)registrar;}
void Start() override;
};


main_behavior.cpp

#include "main_behavior.h"
#include <SlushEngine/Components/camera.h>
#include <SlushEngine/Components/transform.h>
#include <SlushEngine/scene.h>
// Initializing needed variables.
// A scene must be loaded in the global scope of the file
// if it is not it will unload after the function ends which causes the application to crash.
SlushEngine::Scene scene;
// When creating a GameObject it must be a unique pointer.
auto camera_obj = std::make_unique<SlushEngine::GameObject>();
// The camera component.
SlushEngine::Camera *camera_cam;
// Subject to change. (from raylib)
Camera3D camera;
void MainBehavior::Start(){
// Add the camera component to the camera object.
// Initialize values with the constructor.
camera_cam = camera_obj->AddComponent<SlushEngine::Camera>((Vector3){5,0,5}, 90);
// A transform is required for a camera to work.
camera_obj->AddComponent<SlushEngine::Transform>();
// Get the raylib camera from the camera component. (Subject to change)
camera = camera_cam->camera;
// Set the main camera to the newly created camera.
SlushEngine::Core::main_camera = &camera;
// Move the camera objects pointer to the scenes object registry.
scene.AddObject(std::move(camera_obj));
}

void SlushEngine::Behavior::Awake ( )
virtual

Awake is called as the first step after the window is initialized.

Below is an example of Awake and other lifecycles used in a simple way.

#include "behavior_lifecycles.h"
#include "SlushEngine/debug.h"
#include <SlushEngine/Components/camera.h>
#include <SlushEngine/Components/transform.h>
#include <SlushEngine/scene.h>
float update;
void BehaviorLifecycles::Awake(){
SlushEngine::Debug::Log("Ran first!");
update = 0.0f;
}
void BehaviorLifecycles::Start(){
SlushEngine::Debug::Log("Ran second!");
}
void BehaviorLifecycles::Update(float dt){
update += dt;
if(update > 1.0f) {
SlushEngine::Debug::Log("One second has passed!");
update = 0.0f;
}
}
