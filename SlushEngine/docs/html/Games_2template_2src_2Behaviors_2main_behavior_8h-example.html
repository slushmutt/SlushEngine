Behaviors are the main class that game scripts will derive from.

Behaviors are the main class that game scripts will derive from.Behaviors allow game scripts to use lifecycle functions, such as Start(), Update() and many others.
Behaviors can be auto loaded at runtime if the class also inherits from AutoRegister.
The simplest behavior to make the application run without immediately closing is seen below:

#include <SlushEngine/behavior.h>
#include <SlushEngine/auto_register.h>
class MainBehavior : public SlushEngine::Behavior, private SlushEngine::AutoRegister<MainBehavior> {
public:
MainBehavior(){(void)registrar;}
void Update(float dt) override;
void Start() override;
};
