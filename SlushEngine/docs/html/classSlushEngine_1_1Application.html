Detailed Description

Base application class, handles the window and OpenGL context.

The application owns the window, the OpenGL context, and the frame loop. Create an Application, call Initialize() with the resolution and framerate, then whatever behaviors are autoloaded will take over.
Below is a basic example on how to create an application.

Note: You must have atleast one behavior registered along with atleast one scene for this to not immediately close.

Example application setup:

#include <SlushEngine/application.h>
int main() {
SlushEngine::Application app;
app.Initialize(1280, 720, 60, "Game");
return 0;
}
